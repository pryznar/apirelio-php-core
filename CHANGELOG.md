# Changelog

## 0.2.0

- Rebrand the package and PHP namespace from Tracium to Apirelio.
- Publish the shared SDK foundation as `apirelio/php-core`.
- Rename public value objects to `ApirelioCustomer` and `ApirelioApplication`.

## 0.1.0

- Initial shared event model for official Apirelio PHP SDKs.
- Central metadata privacy and ingestion payload limits.
- Framework-neutral HTTP retry and locked file-buffer transports.
